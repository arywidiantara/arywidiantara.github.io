# Ary Widiantara - Personal Website

Personal portfolio and career website for **Ary Widiantara**, a Senior Lead, Data Engineering & Analytics with experience building data organizations, scalable platforms, and trusted analytics capabilities.

The website presents a concise overview of my professional journey, selected business impact, leadership focus, and experience across data engineering, analytics, governance, and software engineering.

## Highlights

- Built and led a 17-member data organization across engineering, analytics, governance, quality, and product
- Led centralized data warehouse and metric governance initiatives
- Reduced monthly BigQuery spend by up to IDR 300M through optimization and improved data modeling
- Introduced LLM-driven analytics capabilities with Claude Sonnet and AWS Bedrock
- Progressed from hands-on software engineering into senior data leadership

## Technology

This is a lightweight static website designed for GitHub Pages:

- Semantic HTML5
- Responsive CSS
- Vanilla JavaScript
- Google Fonts

No build step or external framework is required.

## Local Preview

Run a local HTTP server from the repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
